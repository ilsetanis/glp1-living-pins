# glp1-living-pins

Public image host for GLP-1 Living Pinterest pins, served via jsDelivr:

```
https://cdn.jsdelivr.net/gh/<user>/glp1-living-pins@main/<filename>.png
```

Filenames match the `Media URL` column of the Pinterest bulk-upload CSV produced by
the marketing-platform `export-csv` command. Do not rename files — the CSV points at
these exact names.
